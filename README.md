# AWS EC2 and EBS Project (Linux + Windows)

## 📌 Project Overview
This project demonstrates the deployment and management of AWS EC2 instances (Linux and Windows) along with Amazon EBS storage operations. It includes web server setup, volume creation, attachment, snapshot creation, and restoring volumes from snapshots.

---

## 🎯 Objective
- Launch EC2 instances (Linux and Windows)
- Configure web servers (Apache & IIS)
- Create and manage EBS volumes
- Take snapshots for backup
- Restore volumes from snapshots

---

## ☁️ AWS Services Used
- Amazon EC2 (Elastic Compute Cloud)
- Amazon EBS (Elastic Block Store)
- EBS Snapshots

---

## 🟢 Linux Environment Tasks
- Launched Amazon Linux EC2 instance
- Installed and configured Apache Web Server
- Verified web page using browser
- Created 5 GB EBS volume
- Attached volume to EC2 instance
- Created snapshot of EBS volume
- Created new volume from snapshot

---

## 🟡 Windows Environment Tasks
- Launched Windows EC2 instance
- Connected using RDP
- Installed IIS Web Server
- Verified localhost web page
- Created 5 GB EBS volume
- Attached volume to EC2 instance
- Initialized disk and created new drive (D:)
- Created snapshot of EBS volume
- Created volume from snapshot

---

## 🏁 Outcome
Successfully completed EC2 instance management and EBS storage operations including backup and recovery using snapshots.
